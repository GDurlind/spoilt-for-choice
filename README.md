## Options Analytics Engine

This small project implements basic options pricing, implied volatility, Greeks, volatility visualization, strategy payoffs, and a simple PnL attribution engine. It's designed for learning and interviews — readability prioritized.

Installation (macOS/Linux):

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Run quick example:

```bash
python -m options_engine.main
```

See module code for comments and financial intuition.
